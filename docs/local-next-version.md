# v2.0.1 发布说明：软件环境检查与端口管理优化

基于 v2.0.0，补齐软件健康状态与备份依赖检查，优化端口保存和 SSH 换端口流程。用户已于 2026-10-12 确认正式页面并授权推送发布。实际发行状态、Linux CI 与签名发行包见 [GitHub Releases](https://github.com/zangwp/OLS-WPanel/releases/tag/v2.0.1)。

- 显示各 LSPHP 分支的扩展与 OPcache 配置、当前备份方式所需工具和 cron 服务状态。读取失败明确显示未知；不把命令行缓存状态当成网站工作进程的实时指标。
- 备份依赖修复仅补齐缺失的软件包，先模拟并锁定包版本；涉及已安装软件变更的计划会被拒绝。浏览器离页不会中断已开始的服务器安装任务。
- OPcache 重建使用受管理的 PHP 重启标记；刷新保留尚未保存的性能配置。性能配置页面布局沿用既有实现。
- 普通端口变更保留原有 SSH 和面板访问范围时直接保存；收紧管理入口时保留临时应用、连接验证和超时回退。SSH 新端口可填写，支持识别安装器的既有策略，仍须验证新 SSH 会话后确认。
- 删除邮件入站端口快捷区，补充发件邮箱、授权码及管理员收件邮箱说明。告警连接外部 SMTP，无需因此开放入站邮件端口。

本地 339 项前端回归、双架构 Linux 构建与测试编译、静态检查及中英文模板预览通过；正式发布由原生 Linux CI 与签名流程复核。没有新增数据库迁移，保留已有备份保留设置和自定义端口规则。真实 VPS 的 SSH、端口、软件包安装和邮件送达仍需分别验收，操作约束见 [运维与恢复说明](operations-and-recovery.md)。
