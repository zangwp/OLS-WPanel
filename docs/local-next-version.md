# 历史记录：v1.15.0 开发与验证

本文为历史开发笔记，后半部分保留了当时的发布前状态，不代表当前发布版本、线上入口或待办清单。当前发布请查看 [GitHub Releases](https://github.com/zangwp/OLS-WPanel/releases)，安装流程请查看 [已验证安装说明](verified-install.md)。

当时记录的状态：v1.15.0 已发布，amd64/arm64 CI、ARM64 原生测试、静态检查及签名发布均通过；当时 Cloudflare 安装入口固定到该版。

本次修改：
- 更新检查失败时显示错误，避免误报已是最新版。
- PHP 性能参数批量校验、一次保存和重载；失败恢复旧配置。
- 新站不再强制覆盖 LiteSpeed Cache 对象缓存设置。已有站点可显式迁移当前值，保留其他插件设置。
- 面板后台配置独立完整域名，检查 HTTP 验证路径后申请证书；证书验证通过后切换，并支持自动续期。
- 安装及升级补齐默认虚拟主机的 ACME 验证路径，保留默认根路径访问限制。
- 将部分帮助文字改为问号提示，统一 PHP 内存设置入口，刷新失败保留数据并提示。

验证记录：
- 已执行翻译键检查、Go 模板解析、前端脚本语法及更新检查/PHP 批量请求行为测试。
- 已执行缓存迁移值保留、非法表达式拒绝、域名规范化及证书路径校验的独立本地测试。
- Linux 程序与相关测试包交叉编译通过；安装脚本语法检查通过。
- 本机无可运行 Linux/PHP 环境，Linux 集成测试、PHP 采集器执行、实际证书签发及服务重启尚未验证。

服务器实际证书签发、DNS 和网络配置仍需在目标 VPS 环境验证。发布不等同于已安装服务器自动升级。

## VPS 菜单与布局更新（保留的发布前笔记）

- 输入 o/O 保留面板信息，并在交互终端显示编号菜单。脚本管道不会等待菜单输入。
- 新增 o vps、o menu、o check-update、o system-update、o system-update-status、o clean、o dns、o ip、o tuning、o language。
- 网页分为服务器概况与常用维护，展示 IP、运行时间及资源进度条。
- 普通卸载为 o uninstall；完全卸载为 o uninstall --all，展示删除范围后输入 Y（或 y）确认，回车取消；备份默认保留，删除备份仍单独确认。
- 完全卸载先检查网站目录和数据库归属，删除面板网站数据库；备份默认移出面板目录，删除备份需单独输入 DELETE BACKUPS。Redis 和 Fail2ban 保留，避免影响共享用途。
- 当时发布前的要求：同步更新签名发布包和 Cloudflare 入口版本。当时线上 v1.14.0 不支持新的 --purge 参数，该轮本地修改尚未更新线上入口。
- VPS 配置修改、APT 更新、语言生成、完全卸载均未在真实服务器执行；发布前需在隔离 Debian/Ubuntu 环境验证。

本次新增验证：VPS IP 优先配置切换与原配置恢复、管理员规则保护、卸载确认/备份选择静态检查、嵌入 Python 语法检查均通过；amd64/arm64 交叉编译及相关 Go vet 通过。
