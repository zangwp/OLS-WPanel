# v2.0.0 发布说明：安全边界、任务协调与性能优化

基于 v1.21.7，完成 15 个侧栏模块与登录共用层的逐项源码检查和优化；用户已于 2026-10-12 确认预览并授权发布。详细范围、修复依据、性能证据和服务级验收限制见 [v2.0 审查记录](v2.0-audit.md)。实际发布状态、Linux CI 和签名发行包见 [GitHub Releases](https://github.com/zangwp/OLS-WPanel/releases/tag/v2.0.0)。

- 修复数据库恢复权限边界、备份与恢复竞争、面板更新与网站任务的准入竞争，以及请求体读取占用鉴权锁的问题。
- 减少设置页隐藏板块的请求、重复版本探测与空闲后台查库；限制监控、进程探测和日志扫描的并发与时间预算。
- 保留历史曲线峰谷与真实时间间隔，响应最多 1200 点；修复多个页面的迟响应覆盖、离页轮询和 WordPress 隐藏表格错误。
- 修正封禁期限、WP-Cron HTTP 失败和读取未知状态的显示。未自动降低已有备份保留数量或清理旧备份。
- 修复自定义数据库密码中反斜杠、引号和 `$` 字符的处理，结果只显示固定遮罩；客户端启动后失败明确提示核对连接，不把未知执行结果说成已回滚。

预览使用真实模板及模拟数据；实际 MariaDB、OLS、Linux 文件权限、防火墙、Cloudflare 和通知服务的运行效果仍需单独验收。

## 历史记录：v1.21.7 发布说明：Cloudflare 待命规则

本节记录本次发布范围；发布状态、Linux CI 与签名资产见 [GitHub Releases](https://github.com/zangwp/OLS-WPanel/releases)。

- 已启用的网站即使没有网站封禁 IP，也会创建一条精确匹配已登记域名、但条件永不成立的待命规则。出现封禁 IP 时更新同一个 Rule ID；封禁清空后恢复待命，停用并清理时删除该规则。
- 面板显示 Rule ID 和当前网站封禁 IP 数量，区分“规则已创建，等待封禁 IP”、等待同步、未知数量及写入失败。测试连接仅证明读取成功，不替代创建规则。
- 空名单同样校验主域名、已登记别名与 Zone 的完整覆盖。保留规则所有权和不确定响应恢复检查，不修改管理员规则、不添加虚构封禁 IP。

本次没有新增数据库迁移。每个启用的网站会占用一个 Zone 自定义规则名额，即使名单为空。更新后可保存网站 Cloudflare 设置并点击“立即同步”；规则写入成功不代表 DNS 代理或实际拦截已经验证。仍只需 Zone Read 与 Zone WAF Edit 权限。详见 [Cloudflare 网站防护](cloudflare-website-protection.md)。

## 历史记录：v1.21.6 发布说明：整站备份与恢复

本节记录本次发布范围；发布状态、Linux CI 与签名资产见 [GitHub Releases](https://github.com/zangwp/OLS-WPanel/releases)。

- 备份总览新增“立即整站备份”和“恢复整站”。暂停受管网站写入后，将文件与数据库记录为同一个带校验指纹的备份点，不按相近时间拼接旧备份。
- 保留独立数据库和文件恢复，收起到“单项备份与恢复”；新增无需创建定时任务的“立即全量文件备份”，放在文件备份标题旁。两侧的版本选择、备份信息和恢复操作对齐，手机改为上下排列。数据库备份的下载、恢复、删除按钮保持一行，并分开删除操作。
- 整站恢复保留恢复前的双方安全副本；无法证明回滚完成时继续维护。维护锁在面板重启后仍生效；“检查并恢复网站访问”核对当前操作日志，不将解除维护误报为整站恢复成功。
- 修复整站数据库组件被重复 gzip 压缩的问题；新增导出、一次解压及恢复输入的往返回归，并覆盖导出失败和取消后的残留文件清理。
- 文件写入与备份共用操作锁，覆盖上传、文件管理及已开始的远程导入。网站仍有整站备份或操作数据、或者数据无法核对时，阻止删除网站和改绑主域名。
- 控制台 CPU、内存、负载曲线改为亮蓝、橙、绿，同步对应图例和进度条。
- 网站 Cloudflare 帮助将两项 Token 权限分别列出中文选择顺序，说明区域资源范围，以及已有额外账户权限的 Token 可继续使用。
- 数据库列表默认显示最新 5 份，可展开全部；实际保留数量按网站设置计算，手动与自动备份合计。整站备份点暂不自动轮换，旧备份点需手动删除。

整站备份点目前仅保存在本机，不纳入旧远程同步或自动轮换。支持范围、维护期间的限制、恢复安全副本和人工处理方式见 [日常运维与备份恢复](operations-and-recovery.md)。本机未执行目标 VPS 的真实备份或恢复。

## 历史记录：v1.21.5 发布说明

本次改进网站备份恢复入口与恢复状态可靠性；发布资产与 Linux CI 结果见 [GitHub Releases](https://github.com/zangwp/OLS-WPanel/releases)，恢复范围与安全副本位置见 [日常运维与备份恢复](operations-and-recovery.md)。

- 同一网站的数据库、文件备份并排选择，分别显示生成时间和恢复动作；保留下载、删除以及立即备份/任务管理入口，不将独立生成的包假定为同一个备份点。
- 补齐本地全量网站文件的异步恢复：归档校验、磁盘余量、当前权限核验、原子目录切换、恢复前私有副本及失败回滚；保留当前网站配置和面板管理代码。旧媒体增量缺少完整链，远端文件尚无直接网页恢复入口。
- 同一网站的数据库与文件恢复互斥入队，刷新后续查任务；未知、过期或矛盾结果不能显示已恢复。数据库恢复再次核对当前绑定、持久更新、迁移和维护状态，保留更新失败后的专门回滚能力。
- 修复同秒创建面板数据库备份的命名碰撞，以及缺失本地全量基线后的增量备份选择；显式删除基线会清理增量时间戳。
- 修正 WordPress 更新检测策略对文件修改限制的误判，明确资源统计、媒体增量和数据库保留的范围。

本地回归与中英文真实模板预览通过。Windows 测试的 Linux 原子交换、身份和 Statfs 使用明确替身，Linux 原生测试由双架构 CI 验证；本次不执行目标 VPS 的真实备份或恢复。没有新增数据库迁移。恢复后仍需核对网站访问、数据库版本和运行时/CDN 缓存，不自动重启所有网站。

## 历史记录：v1.21.4 发布说明

本节记录本次发布范围；发布状态与签名资产见 [GitHub Releases](https://github.com/zangwp/OLS-WPanel/releases)，安装流程见 [已验证安装说明](verified-install.md)。

本次修改：

- 安全摘要使用文件保护应用结果、最近在线检查和 WordPress 库存采样作为带时间的依据，区分“已配置”“最近检查成功”和实际请求防护。没有独立验证能力的项目改为进入设置、告警、检查结果或备份页面，不再提示点击不存在的验证按钮。
- 文件保护应用完成且 WordPress 文件修改限制已确认时，后台编辑显示“受文件保护约束”，隐藏重复的勾选和保存按钮。原独立编辑设置保留；应用未完成、失败、状态未知或临时解锁时，不显示已经接管。
- 临时维护读取实际文件锁标志，不把“允许管理员临时解锁”误当成文件保护已启用。文件锁标志被清除后，仍报告临时解锁、回锁和回锁失败；旧的编辑策略验证缓存不能覆盖正在变化或未知的文件保护状态。
- 维护状态、窗口或实际锁标志变化后刷新安全摘要；读取失败会撤下旧的文件保护依据，较早发出的响应不能恢复旧成功状态。没有变化的维护轮询不会重复运行安全探针。
- 在线监控显示最近实际 HTTP 检查结果及采集时间；异常监控显示最近 WordPress 库存采样结果。尚未检查、样本过期、配置变化、告警未启用及检查失败都有明确说明。采样成功不表示网站不存在异常，也不表示全部防护都已经生效。
- 控制台 CPU 保留柔和蓝色，内存改为暖金色，负载改为砖红色，并同步图例和对应进度条颜色。

验证记录：

- 网站详情加载、维护状态转换、安全摘要与设置行为的 59 项定向前端测试通过，包含临时解锁、回锁失败、未知状态、旧响应和稳定轮询的回归。
- 中英文翻译键检查与相关文件差异检查通过。

升级说明：本次没有新增数据库迁移。更新后可在网站安全页面核对当前应用结果、维护状态和依据时间。在线检查的采样记录保存在进程内，面板重启后会先显示等待检查，由原有调度任务产生新的采样结果。

## VPS 菜单与布局更新（保留的发布前笔记）

- 输入 o/O 保留面板信息，并在交互终端显示编号菜单。脚本管道不会等待菜单输入。
- 新增 o vps、o menu、o check-update、o system-update、o system-update-status、o clean、o dns、o ip、o tuning、o language。
- 网页分为服务器概况与常用维护，展示 IP、运行时间及资源进度条。
- 普通卸载为 o uninstall；完全卸载为 o uninstall --all，展示删除范围后输入 Y（或 y）确认，回车取消；备份默认保留，删除备份仍单独确认。

- 当时发布前的要求：同步更新签名发布包和 Cloudflare 入口版本。当时线上 v1.14.0 不支持新的 --purge 参数，该轮本地修改尚未更新线上入口。
- VPS 配置修改、APT 更新、语言生成、完全卸载均未在真实服务器执行；发布前需在隔离 Debian/Ubuntu 环境验证。
