# v2.0 逐模块审查与本地修复记录

审核日期：2026-10-11。基线：v1.21.7。本轮以减少重复读取、保持任务与安全状态准确、修复可复现缺陷为目标。本地预览已完成，用户于 2026-10-12 确认并授权发布 v2.0.0。此页保留历史审核记录；当前可安装版本与签名发行包见 [最新发行版](https://github.com/zangwp/OLS-WPanel/releases/latest)。下面保留本地检查的真实边界，不将交叉编译改称原生执行。

入口盘点覆盖 **15 个侧栏模块、登录与共用层、22 个完整页面、300 条路由**；双语模板 fixture 共 44 份。这些数字是范围清单，不能解读为 300 条路由均做过端到端验收。下面分别记录源码审查、本地复现与修复，以及仍需真实 Linux/外部服务验证的部分。

## 可以证实的减负收益

- **图表数据量有上限。** 同一组每分钟合成样本、未压缩 Go JSON：7 天由 10080 行/459055 字节变为 1136 点/76290 字节；15 天由 21600 行/853995 字节变为 1169 点/68418 字节。新增时间戳和说明也计入新响应；原始历史不删除，峰值不做平均消除。
- **网站资源采样复用。** 同一个 15 秒窗口普通请求共享完成快照；并发冷读取只启动一次 ps 和一次网站映射 SQL。手动 fresh 跳过完成缓存但合并在途采样，一个等待者退出不打断其他等待者。
- **隐藏板块少发普通请求。** 设置页首次访问板块才读取；实际运行任务保持 ID/状态，不通过销毁界面丢失跟踪。历史成功结果不会每次读取都使暖缓存失效。
- **后台空闲少查库。** WordPress 库存/更新 worker 有入队唤醒与最长 30 秒空闲退避；持久队列仍是依据，保留周期轮询和租约恢复。原先约每秒的空闲循环成本是代码估算，不是 WAL/fsync 实测。
- **慢命令不占全局状态锁。** 守护服务操作仍互斥，外部查询/启停不在状态快照的写锁中等待；软件与更新只读探测有并发合并和有限失败缓存，不缓存实际守护状态或跳过升级验证。
- **网站监控并发有界。** 32 个本地 HTTP 服务的旧实现峰值为 32，修复后不超过 4；最久未检查优先，未完成样本保留未知状态。该测量不是公网 VPS 请求时延或整机 CPU 比较。

本轮没有测量真实 VPS 的 CPU、RSS、IOPS、WAL 或首屏耗时百分比，不用请求/点数减少替代这些结论。控制台实际 Chart.js/Alpine 渲染已验证不均匀时间间隔、峰值和时区；合成 fixture 不代表生产数据。

## 数据恢复与运行任务的关键边界

SQL importer 创建、授权、身份检查均在清库前完成；只使用面板确实创建的账户，账户碰撞不修改或删除未知账户。schema GRANT 中 `_`/`%` 转义，禁用 local-infile/重连与环境覆盖；没有失败后切回 root 导入的路径。普通 DEFINER 重绑只是兼容处理，授权边界仍是 MariaDB 权限。

密码变更在独立连接设置会话级 `NO_BACKSLASH_ESCAPES`，只从 stdin 传入 SQL；客户端未启动可恢复旧网站配置，启动后超时/失败不能证明 ALTER 未提交，因此保留请求的新配置并提示核对连接，不虚报数据库已回滚。5 项真实 PHP 求值确认特殊字符保持一致；MariaDB 字符串/客户端处理由官方文档与源码核对，实际服务认证未执行。普通数据库创建/删除等旧 DDL helper 尚无统一期限，本轮未直接加入可能产生部分完成结果的通用超时。

恢复后的 DEFINER 对象可能需要保留锁定的受限账户；其真实执行语义需要服务集成。旧包没有导出的 routine/event 不能凭空恢复；跨库对象或需要高权限的 dump 会明确失败，不临时扩大授权或改变服务器全局设置。

面板控制的更新与恢复取得相同准入屏障，避免“检查队列为空”后插入新写任务；忙碌自动更新下轮重试，不丢成熟等待时间。关闭等待有限，运行任务保留原执行/回滚上下文。进程被外部强制结束时，须核对持久任务、维护记录与安全副本，不能宣称回滚已完成。

独立数据库/文件包不因时间接近自动配成整站备份；整站备份点由同一次受控操作明确关联。备份保留、增量链、远程副本、回滚安全副本分别核对。独立数据库自动/手动备份与同站恢复互斥；继承凭证不由请求 JSON 或队列持久记录恢复，不释放调用者的操作锁。

保留数量按已有设置计算：独立数据库默认 7 份，文件任务默认 3 份，各自可配置；数据库列表默认展示最新 5 份是显示限制。手动与自动数据库备份合计计入保留策略，整站备份点仍需手动管理。本轮没有批量降低保留数量或据此删除旧备份。文件任务“两周一次”现有实现为每月两个日期、间隔 15 天，不能当作全年严格每 14 天；夏令时及运行中时区变化仍需专门调度验收。

## 遗留项与发布前验收限制

1. 在受支持的 Debian/Ubuntu、amd64/arm64 上核对实际 OLS 配置检查/重启、IPv4/IPv6 监听、nft/SSH 回退、文件 owner/mode 与挂载边界。跨架构编译不证明这些行为。
2. 用隔离 MariaDB 验证恢复身份、跨 schema 权限拒绝、特殊 DEFINER 与 routine/event、失败回滚；完整网站恢复还需真实原子目录交换、冻结与安全副本验收。
   新建/迁移数据库的 schema 通配符授权已修复；历史账号尚无完整私有归属证据，未自动撤销或重写旧权限。旧库名含 `_` 的账号须先核对 SHOW GRANTS 再制定迁移。
3. 按已授权环境验证 Cloudflare 规则、Token 权限、代理覆盖与实际边缘拦截，SMTP/Webhook 投递、ACME 和外部 AI 连通。本轮没有使用用户凭据或发送真实通知。
4. 大目录分页、日志详情高频深页、AI 逐用户映射、OOM journal 输出上限/游标，以及低频指标清理是后续性能范围。没有直接用截断或放宽安全限制掩盖这些问题。
5. 缓存/取消保证的是已声明的读取路径与预算；DNS manager、部分诊断采样、直接全局安全/CF 写入仍有自身生命周期。页面离开或 POST 回应丢失均不证明后台任务停止，必须查持久状态。
6. 本地统一检查与预览已完成并获确认；本报告不以本地 fixture 宣称真实 VPS、Linux CI 或生产发布已经通过。发布检查另由原生 CI、签名发行包与线上安装入口回执证明。
