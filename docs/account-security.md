# 账户安全中心

账户安全中心自 v1.18.0 提供。入口为“安全设置”，分为账户登录、网站防护、访问控制、日志告警。原有 Fail2ban、CDN 信任、白名单及端口确认回滚流程继续使用。

## 双因素认证

在“账户登录”中选择设置双因素认证，输入当前面板登录密码，用支持 TOTP 的验证器扫描页面上的二维码。也可手动输入设置密钥，或在手机上使用页面的验证器链接。二维码由面板本地生成，与密钥、链接一同通过禁止缓存的已认证接口返回，不请求外部二维码服务。二维码显示失败时，手动输入方式仍可使用。

待绑定设置十分钟后过期，并绑定发起操作的当前会话。输入验证器中的六位动态码确认后才启用。服务器使用 RFC 6238 HMAC-SHA1、30 秒周期，允许前后一个周期的时钟偏差；已经使用的动态码不能再次使用。请保持服务器和手机自动校时。

启用后会一次性显示十条恢复码。每条为 128 位随机值，仅能使用一次；数据库只保存哈希。下载或复制后，确认已经安全保存。页面刷新或关闭后无法再次查看原恢复码；重新生成会使所有旧恢复码失效。不要把恢复码与登录密码保存在同一处。

登录先验证账号密码，再输入动态码或恢复码。完成两步前不创建登录会话。关闭双因素、重新生成恢复码、修改面板账号密码或 BasicAuth 凭据，都要求当前面板密码；启用双因素时还要求有效动态码或恢复码。启用、关闭或更换恢复码后撤销其他会话；修改面板用户名或密码撤销全部会话。原有 BasicAuth 两层密码不等于双因素认证。

动态码/恢复码连续验证失败有账户级限制；敏感操作也有独立的短时请求限制，界面会显示等待提示。部署默认不替已有用户启用双因素，需要管理员完成上述绑定。

## 密钥、备份与恢复

TOTP 密钥使用 AES-GCM 加密后保存于面板数据库。加密密钥是数据库同目录的 `account-mfa.key`，默认路径为 `/www/ols-wpanel/account-mfa.key`，长度 32 字节，Linux 权限 `0600`。不要输出其内容、放入代码仓库、通过聊天发送，或当作可公开下载的附件。

首次启动创建独立加密密钥。已有加密绑定数据而密钥丢失时，服务拒绝初始化，不会生成替代密钥或降级到仅密码认证。

**普通面板数据库备份不包含 `account-mfa.key`。** 在启用双因素前，将该文件通过受控的主机管理通道单独保存到加密备份位置。迁移或灾难恢复必须同时恢复原数据库及与其配对的原加密密钥，文件保持所属用户和 `0600` 权限；不要用其他服务器或新生成的密钥替换。安装器的私有 repair 快照会额外保留现有加密密钥，不改变普通数据库下载格式。

恢复码可以解决验证器丢失，但无法代替丢失的数据库加密密钥。缺失加密密钥时，应先从安全备份恢复它；不要直接清空双因素表或删除绑定。恢复旧数据库会同时恢复当时的认证状态和恢复码使用状态，因此恢复完成后应立即重新生成恢复码并检查双因素状态。

回退构建也必须包含此双因素功能；v1.18.0 以前的构建不会执行新增验证。启用双因素后，不应将历史二进制作为透明回退方式。首次升级应先确认更新任务已完成、服务健康并能够正常登录，再绑定双因素；不要在升级回滚仍可能发生时修改账户保护状态。

## 会话与登录记录

在线会话显示浏览器信息、IP、登录时间和最近活动时间，标明当前会话。可以退出单个其他会话或全部其他会话。列表使用独立展示编号，不返回认证令牌。会话仍使用三十分钟滑动过期，重启面板后需要重新登录。

登录审计持久记录面板网页/API 的登录成功、失败、封禁、退出、凭据变更、双因素变更、恢复码使用和会话撤销等事件。保留最近九十天，最多一万条；清理短时防爆破计数不删除审计记录。用户名修改时同步迁移历史归属与通知偏好，历史中的账户名随之更新。该单管理员面板也展示尝试其他用户名的失败及网关封禁记录。它不替代操作系统审计，也不记录管理员直接通过主机命令或 SQLite 修改的内容。

## 异常通知

“日志告警”可管理账户安全通知，复用“告警设置”中的 SMTP 和 Webhook。通知开关默认开启，但只有配置渠道后才实际发送。开发预览、回归测试均不向真实渠道发送消息。

新 IP 与浏览器组合的成功登录、使用恢复码、关闭双因素和修改凭据会触发通知。首次登录也属于保留记录中首次出现的环境；IP/浏览器组合是环境提示，不能作为可靠的设备身份认定。

同环境同类事件十五分钟内去重，每账户每小时最多五条。投递使用有界队列和网络超时；失败、未配置、关闭及限速状态可在审计中查看。发送失败不会撤销已完成的操作或让一次性恢复码丢失。待投递事件在重启后继续处理；已经标记失败的事件保留失败状态，管理员应修复渠道。

## 配置保存保护

网站防护配置只有在完整读取成功后才允许修改；失败时显示原因并提供重试。各保存操作共用写入锁，避免重复提交；CDN 分组拥有独立加载状态。页面分别提示“已保存但运行状态读取失败”和已成功刷新的运行状态，提交白名单更新任务不会显示成任务已经完成。

## 开发验证

新增服务测试使用真实 SQLite，覆盖 TOTP 标准向量、密钥保护、过期/重放、并发恢复码消费、审计事务回滚与通知限速。会话/认证和前端状态测试覆盖未完成 MFA 不创建会话、错误验证码不退出有效会话、跨账户会话隔离、撤销生效、加载失败禁用保存等。

Windows 本地认证隔离测试直接复制生产认证/会话源码，只替换 Linux 防火墙等外部边界；不代表执行过目标 VPS 的完整集成测试。发布前仍需在隔离 Linux 环境验证升级、HTTPS 登录、真实验证器、重启/恢复及测试收件人的通知投递。

实现参考：[RFC 6238](https://www.rfc-editor.org/rfc/rfc6238)、[OWASP 双因素认证](https://cheatsheetseries.owasp.org/cheatsheets/Multifactor_Authentication_Cheat_Sheet.html)、[OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。
